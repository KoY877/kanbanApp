# Copilot Instructions

## Contexte

Projet fullstack :

- Backend : Spring Boot (JWT, Security)
- Frontend : Angular (HttpClient, interceptor)

## Règles

- Toujours vérifier la correspondance frontend ↔ backend
- Vérifier les endpoints REST (GET, POST, PUT, PATCH, DELETE)
- Vérifier le flow JWT (login, refresh, logout)
- Vérifier les erreurs 401 / 403
- Expliquer les corrections simplement (niveau junior)
- Préciser le nom des fichiers à corriger
- Toujours donner :
  - problème
  - cause
  - correction
  - explication

## Bonnes pratiques

- API REST propre (/boards au lieu de /boards/all)
- Ne jamais exposer d'entités directement → utiliser DTO
- Vérifier la sécurité (JWT, cookies, headers)

## Style de réponse

- clair
- pédagogique
- concret
- avec exemples
